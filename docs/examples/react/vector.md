# Vector basemaps

OpenFreeMap's styles (Positron, OSM Liberty, OSM Bright) drawn from its vector tiles of OpenStreetMap data in workers, and a subset of the data on its own layer, restyled: rivers and water areas in a strong blue.

In React (`isard/react`); the same in [TypeScript](../vector).
