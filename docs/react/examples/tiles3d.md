# 3D Tiles

The photomesh of the Métropole Européenne de Lille (2020, 5 cm, open data) streamed as 3D Tiles over the IGN orthophoto. Its server is slow on a cold file: the first tiles may take a few seconds.

In React (`isard/react`); the same in [TypeScript](../../examples/tiles3d).
